# 个人拉片工作台 v0.1.1

发布日期：2026-10-25

这是项目首个 GitHub 正式更新版本，安装包内含 Electron、FFmpeg/FFprobe、libmpv、内嵌 Python 及检测依赖，无需另外安装运行环境。

## 主要更新

- 启动时扫描旧数据目录，并支持导入旧项目及资源目录。
- 镜头检测前校验项目和视频源，提供可读的恢复指引。
- Session 恢复失败时引导导入，不再静默清空项目状态。
- 数据根目录迁移向导，支持迁移、跳过和取消回滚。
- 设置保存后回读校验，并显示实际 `settings.json` 路径。
- 设置界面支持 10 项可配置路径，包含继承、独立覆盖和还原默认。
- 环境变量锁定时显示完整解除指引和检测按钮。
- 静帧记录截图时间，并将同一时间码写入文件名、PNG 元数据、界面、PDF 和 Word。
- 统一处理弹层与原生视频窗口层级，并保护用户手动设置的播放器层级。
- 支持右键或 Delete 键删除镜头/静帧，同时清理关联记录、图片文件和越界路径保护。
- 修复镜头检测环境结果被 IPC 信封误判、按钮无响应的问题。

## 系统要求

- Windows 10/11 x64

## 安装

优先下载 `个人拉片工作台 Setup 0.1.1.exe` 安装。免安装用户可下载 `win-unpacked` 压缩包并解压后运行 `个人拉片工作台.exe`。

源码请下载 `Source code (zip)` 或本次附带的源码压缩包。
