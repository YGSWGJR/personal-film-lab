# v0.3.2 发布说明（分镜墙 BUG 修复版）

- 分支：`main`；tag `v0.3.2`
- 日期：2026-11-07

## 修复（用户实测反馈）

1. **分镜墙 HUD 按钮全部无反应（根因修复）**：画布抓手的 `pointerdown` 会对所有目标启动指针捕获，把按钮的 `click` 吞掉。现已排除 HUD 按钮、删边按钮、端口等交互目标——放大/缩小/复位/导出/整理全部恢复可用（smoke 断言：点击放大按钮后缩放值上升）。
2. **连线中点 × 无法断开**：同根因（点击被捕获）+ 删边按钮位置偏离线外（卡片高度常量与实际不符）。两处均已修复；× 常显并加大可点区域；断言：建边 → 点 × → 连线消失。
3. **连线形态对齐竞品**：贝塞尔大弧改为**直线 + 箭头**；卡片两侧常显端口方块（右侧绿色出端口可拖线、左侧蓝色入端口）。
4. **有拉片素材时的分镜本入口**：点击「分镜墙」现在弹出**选择卡**——本项目分镜本 / 新建分镜本 / 最近分镜本（此前直接进入项目画布，无法选择）。
5. **独立分镜本节点创作**：右键空白 → 添加节点·导入照片（系统文件选择器）/ 黑底+文本 / 白底+文本；节点删除为真删；节点编辑卡（名称/持续时间/笔记）。
6. 门控 `SMOKE_WALL_UI` 重构为**分段执行**（每段独立超时自愈），并新增 HUD 点击、删边点击、选择卡断言。

## 投影到拉片界面（说明）

「分镜本按连线顺序呈现到拉片界面（时长→时间线、标注→标签、笔记→笔记、并行节点→多宫格+无限轨）」依赖时间线架构改动，**规划在 v0.4.0**；本版已交付其地基（分镜本实体、节点数据模型、放映内多宫格预览与多轨条）。
