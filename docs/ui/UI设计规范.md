# 个人拉片工作台 · UI 设计规范（S13）

> 版本：V1（2026-10-24）｜ 适用：`feature/ui`（codex S08 落地）｜ 依据：产品方案 V2 + S01 架构文档
> 本规范所有色值 / 字号 / 间距 / 尺寸均量化，codex 逐项引用即可实现，无需再自行推断。

## 1. 设计原则

- **暗色影视风格**：界面整体深灰蓝底，信息靠层级和强调色区分，降低长时间拉片视觉疲劳。
- **时间轴一致性**：四层时间轴（影片 / 镜头 / 标注 / 音频）严格对齐同一时间基准，颜色语义全局唯一。
- **信息密度优先**：桌面工具以"一屏看全"为目标，正文 12px 起，允许紧凑行距；最小可点区域不小于 28×28px。
- **一切经 IPC**：渲染层不触碰 Node / SQLite，本规范只约束视觉与交互，不改变 S01 模块边界。

## 3. 字体与字号

- 中文字体栈：`"Microsoft YaHei", "PingFang SC", "Noto Sans SC", system-ui, sans-serif`
- 数字 / 时间码 / 等宽场景：`"Cascadia Mono", "Consolas", "SF Mono", monospace`
- 全局基准字号 12px；缩放倍数固定（不随系统缩放变化，应用内以 100%/125%/150% 三档缩放）。

| 层级 | 字号 / 字重 | 场景 |
|---|---|---|
| 窗口标题 / 大标题 | 14px / 600 | 顶部工具栏标题、模态框标题 |
| 区块标题 | 13px / 600 | 左栏"镜头列表"、右栏"详情"等 |
| 正文 | 12px / 400 | 默认正文、镜头卡片文字 |
| 辅助 | 11px / 400 | 时间码、统计数字、工具提示 |
| 标签 / 徽标 | 10px / 600 | 景别徽标、状态标签 |
| 时间码（等宽） | 12px / 500 | `00:00:00.000` 类显示 |

行高：正文 1.5，标题 1.3，紧凑列表 1.2。

## 4. 间距网格与布局

- **基数 8px**：4 / 8 / 12 / 16 / 24 / 32 / 40。禁止出现 5 / 7 / 13 等非 4 倍数间距（时间轴内部 1-2px 微调除外）。
- 应用内边距：窗口 0（全屏工作台）；面板内边距 16px；卡片内边距 12px；列表行内边距 8px 12px。
- 栏间距：三栏之间 8px 槽，栏面板用 1px `border` 分隔。

## 6. 组件规范

### 6.1 顶部工具栏（40px）
从左到右：应用名"个人拉片工作台"（13px/600，`text-primary`）→ 主按钮组：**导入**（主）、**镜头切分**（主）、**静帧截图**（次，快捷键 S 提示徽标）、**导出分镜本**（次）→ 右侧：统计（图标按钮）、设置（图标按钮）。
- 快捷键在按钮内以小徽标显示（`text-faint` 10px，如 `S`）。
- 禁用态：文字 `text-faint`、无边框，不响应 hover。

### 6.2 左栏 · 镜头列表（260px）
- 区块标题"镜头列表" + 计数徽标（如 `24`，`text-muted` 10px）。
- 列表项 = 缩略图（64×36，圆角 4，背景 `bg-deep`）+ 镜号（等宽 11px）+ 景别徽标（10px）+ 时长（等宽 11px `text-muted`）。
- 选中项：左侧 2px 红条 + `accent-red-soft` 底 + `accent-red` 描边。
- 点击项 → 播放器 seek 到 `startMs`（S08 实现，S01 §8.2）。

### 6.3 中栏 · 播放器 + 示波器 + 四层时间轴
- 播放器：16:9 自适应容器，背景 `bg-deep`；**libmpv 原生子窗口嵌入区**（S04 实现，DOM 不可覆盖；控件放在其下方工具栏）。
- 示波器面板：播放器下方折叠区，默认高 174px；直方图 / 波形图 / 矢量图 / 分量图 / CIE 1931 五 Tab，参考线开关，canvas 按 devicePixelRatio 清晰缩放。
- 播放控制条（高 36px，位于时间轴上方或下方，本规范建议**时间轴下方**）：播放/暂停、±1 帧、±1s、时间码（等宽 `00:00:00.000 / 00:23:40.039`）、音量滑杆。
- **四层时间轴（总高 130px，下方附刻度）**：
  - 影片层（24px）：整片时间底条 `info-blue`；播放进度填充 `#60a5fa`；拖动 seek。
  - 镜头层（28px）：橙 `accent-orange` 分段色块，块间 1px `bg-deep` 间隙；选中镜头块白描边 2px；**块边界可拖动微调**（S08 实现）；当前播放镜头块高亮 `accent-gold`。
  - 标注层（24px）：绿 `ok-green` 2px 标记点（截图/笔记/标签），hover 显示 tooltip（11px，`bg-raised` 底）。
  - 音频层（30px）：青蓝镜像 peak/RMS 包络，中线为 0 振幅，红色播放头联动；Ctrl+滚轮缩放、Shift+滚轮平移、点击/拖动 seek。
  - 时间刻度：1px `border` 线 + 11px `text-faint` 等宽数字，位置随缩放级别（秒/分/时）变化。

### 6.4 右栏 · 镜头详情卡（300px）
- 顶部：镜号 + 时间区间（等宽 11px）+ 锁定开关（锁定时橙色 `accent-orange`）。
- 静帧大图：16:9 宽自适应，背景 `bg-deep`；下方"截图"按钮（次）；**标注覆盖层**（SVG：框选/箭头/文字，归一化坐标 0~1）。
- 标签网格：按六类（景别/机位/运镜/光线/声音/剪辑）分组，每组标题 11px/600 + 可选 chip；选中 chip 红底；"+"新增自定义标签。
- 笔记区：多行输入（高 ≥72px，`bg-raised`），自动保存；术语库入口按钮。
- 术语库（可折叠面板）：术语名 + 释义两列，"一键插入标注"。

### 6.5 模态框
- **导入**：来源 Tab（本地 / 链接）；本地=文件选择 + 预览元信息；链接=URL 输入 + 解析按钮 + 清晰度下拉 + 合规提示文案（S16）。
- **导出分镜本**：镜头范围勾选列表 + 表头自定义 + 图策略（缩略图/大图）+ PDF/Word 选择 + 导出按钮（S11）。

### 6.6 空状态
- 无项目 / 无镜头 / 无截图三种空状态：居中插画（S12 千问生成）+ 主文字（13px/600）+ 引导（12px `text-muted`）+ 主按钮。

## 7. 交互与状态

| 状态 | 表现 |
|---|---|
| hover | 背景 `bg-hover`（面板元素）/ 文字亮度提升（链接） |
| active / 按下 | 背景再深一档（`#2c3a52` 或降透明度） |
| focus | 1px `border-strong` 描边 + `accent-gold` 外圈 2px（键盘可达性） |
| disabled | `text-faint`，无边框无 hover |
| 选中（镜头/项） | `accent-red` 描边 2px + `accent-red-soft` 底 |
| 拖拽（时间轴边界） | 拖拽中边界线 `accent-gold` 2px；松手落值，圆整到帧 |
| 加载 / 转码 / 检测中 | 按钮内 14px spinner（`accent-orange`）+ 文案，如"转码中 45%" |

- 过渡：颜色/背景 120ms ease；面板显隐 160ms ease。
- 所有列表支持键盘：↑↓ 选镜头、Enter 跳转播放、Delete 删除（二次确认）。

## 9. 实现备注（给 codex）

- 时间轴与播放进度联动：`player:event:time`（节流 100ms）驱动进度填充与当前镜头高亮。
- 镜头边界拖动：改 `shot:update`（S06 数据层已有），松手后 `endMs` 圆整到帧（1000/fps）。
- 缩略图：优先用 still `role=auto-thumb`，无则取镜头起点 `media:extractFrame`。
- 三栏可折叠：左/右栏加折叠按钮（28×28 图标），折叠后中栏独占。
- 暗色滚动条样式为全局 CSS；字体栈全局声明，禁止各组件自定义字体。
- 本规范与 `ui-wireframe.html` 配套使用；线框为静态展示，标注了各区域尺寸，布局以此为准。
