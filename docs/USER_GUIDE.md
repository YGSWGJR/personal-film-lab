# 个人拉片工作台使用说明

适用版本：`0.3.0`  
系统：Windows 10 / 11 x64
更新日期：2026-11-05

个人拉片工作台用于本地影片分析。导入影片后，你可以自动或手动切分镜头，逐镜填写景别、机位、运镜、台词和笔记，截取并标注静帧，查看学习统计，并导出 PDF 或 Word 分镜本。

软件默认在本地处理画面与项目数据。完整安装包含本地 Qwen3-VL 模型，不需要把影片上传到在线 AI；未安装本地 AI 资源时，可以在设置中切换 OpenCV 备用引擎。

## 安装准备

### 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11 64 位 |
| 推荐空间 | 安装目录至少 30 GB，另留视频与项目空间 |
| GPU | 支持 DirectX 11；NVIDIA 显卡可加速转码与检测 |
| 内存 | 建议 16 GB 或更多 |
| 本地 AI | 11.31 GB 离线资源，8 GB 显存可运行但速度较慢 |

### 推荐安装方式

1. 打开仓库根目录，运行下载脚本：

```powershell
.\scripts\download-release.ps1 -Tag v0.2.0 -Destination .\downloads
```

2. 确认目录中有 `个人拉片工作台 Setup 0.2.0.exe` 和 `个人拉片工作台-0.2.0-local-ai.7z`。
3. 把两个文件放在同一个文件夹，不要改名。
4. 双击 Setup，选择至少保留 30 GB 空间的安装目录。
5. 安装器解压应用主体和本地 AI 资源。
6. 从桌面或开始菜单启动“个人拉片工作台”。

如果缺少 `local-ai.7z`，Setup 仍可安装应用主体。此时本地视觉模型不可用，需要在设置中选择“OpenCV（备用）”。

## 首次启动

软件优先把设置、会话和 Chromium 数据写入 `G:\拉片\软件数据`。如果 G 盘不存在或不可写，会自动回退到 Windows 当前用户的 Electron 数据目录。

首次启动会：

1. 初始化 SQLite 数据库。
2. 检查本地 AI 运行时和模型。
3. 恢复上次项目，或扫描其他数据目录中的可恢复项目。
4. 没有项目时进入示例工作区。

如果启动后检测环境显示“环境未就绪”，先检查本地 AI 资源是否完整；仍可切换到 OpenCV 备用引擎继续完成镜头切分、标注和导出。

## 主界面

主界面由顶栏、三栏工作区和状态栏组成。

| 区域 | 用途 |
|---|---|
| 顶栏 | 导入、示例/最近项目、镜头检测、截图、导出、AI 助手、保存、统计和设置 |
| 左侧 | 镜头列表、缩略图和手动打点 |
| 中央 | 原生播放器、时间码、播放控制、V2/V1/A1 时间线 |
| 右侧 | 镜头详情、标签、笔记、术语、静帧与画面标注 |
| 状态栏 | 当前项目、镜头数、标注数、分辨率、帧率和版本 |

左右栏可折叠，以扩大时间线或视频预览区域。

## 导入影片

点击“导入影片”，选择本地视频。软件会先探测视频并建立项目，原片可立即播放，代理转码在后台继续。

代理档位可在设置中选择：

- 360p：速度优先，适合快速浏览。
- 540p：默认档位，兼顾速度和画面。
- 720p：清晰度优先，需要更多转码时间。

同一视频与同一档位会复用已有代理缓存。播放或检测时，软件会自动减少后台转码并发。

当前版本只支持本地文件。B 站或 YouTube 链接导入尚未实现。

## 镜头切分与标签识别

### 第一步：镜头切分（自动应用）

1. 点击顶栏“镜头切分”（项目已有镜头时显示“重新切分”）。
2. 软件使用 TransNetV2 + OpenCV 混合引擎检测切点；模型缺失时自动回退 OpenCV，不影响切分。
3. 切分完成后镜头**立即写入项目**并出现在镜头列表与 V1 轨道，可立刻播放、切分、合并、打标签、写笔记和导出。
4. 顶栏显示“切分已应用 · N 个镜头”，可点击“开始标签识别”或关闭提示（关闭后仍可用顶栏“标签识别”按钮进入）。
5. 若部分候选与人工/锁定镜头重叠，会被跳过并如实提示。

### 第二步（可选）：标签识别

1. 由你主动点击“标签识别”启动；切分不依赖 Qwen，跳过此步完全可用。
2. Qwen3-VL 分析每个已落库镜头的代表帧，完成后打开“标签识别结果”预览。
3. 预览不写库：可关闭（结果暂时保留，可再次查看）、可取消，已切分镜头不受影响。
4. 两种应用方式：
   - **保留我的标注，应用其余**（推荐）：你手动改过的景别/摄法/备注/标签会被保留，其余字段应用 AI 结果。
   - **覆盖全部选中镜头**：AI 结果覆盖选中镜头的景别、摄法、备注和六类受管标签（自定义分类标签保留）。需二次确认。
5. 应用后显示更新统计（镜头数/字段数/标签数/保留人工项）。
6. 标签任务运行时可以继续编辑镜头；应用时会自动跳过因切分/合并而变化的镜头，不会串写。
7. 台词、笔记、静帧、缩略图和镜头范围永不被标签应用修改。

### 模型缺失降级

- TransNetV2 模型缺失：自动回退 OpenCV 切分，顶栏显示降级警告。
- Qwen 未安装或未启用：“标签识别”按钮会明确提示不可用；切分与手工标注不受影响。

## 使用时间线

时间线包含三条轨道：

| 轨道 | 内容 |
|---|---|
| V2 | 缩略图参考轨，只读 |
| V1 | 镜头剪辑轨，可选中、调整边界和锁定 |
| A1 | 音频波形轨，显示 M/S 状态 |

点击右上角缩放胶囊可调整：

- 轨道高度：1、48、96、144、192、240 px。
- 时间密度：24、48、96、192、384、768 px/s。
- 区域导航：当前缩放不能显示全片时，可拖动导航条快速平移。

时间线缩放：在标尺或轨道区**直接滚动滚轮**即可以鼠标所在时间为锚点连续缩放（24–768 px/s，重开项目不回弹）；`ALT+滚轮` 或 `Shift+滚轮` 平移；`Ctrl+滚轮` 在标尺切换密度档、在轨道区切换轨道高度档；`+/-` 调整密度。缩放到 1 px 高度可临时折叠轨道。

### 手动切分与合并镜头

自动检测不准确时，可以直接在 V1 编辑镜头，不必重新运行识别。

切分一个镜头：

1. 在镜头列表或 V1 中选中目标镜头。
2. 把播放头移到镜头内部的目标画面。
3. 点击时间线工具栏“切分”，或在 V1 上点右键选择“在此时码切分”，也可按 `Ctrl+K`。
4. 新右段会自动继承景别、摄法、台词、备注和标签，并生成自己的缩略图。

合并两个镜头：

1. 先选中一个镜头，再按住 `Shift`、`Ctrl` 或 `Cmd` 点击时间上无缝相邻的另一个镜头。
2. 两个镜头会在列表和 V1 中同时高亮，点击“合并”或按 `Ctrl+Shift+G`。
3. 也可以在镜头右键菜单中直接选择“合并前一镜头”或“合并后一镜头”。
4. 开启删除二次确认时，会先说明第二个镜头记录将被删除，但标签、笔记和静帧会迁移并保留。

拆分和合并都会写回真实镜头数据，因此镜头列表、右侧详情、时间线、导出和 MCP 会立即使用相同结果。操作按项目帧率对齐；锁定镜头不能编辑；手动编辑过的镜头在重新检测时受保护。

现有笔记表没有时间字段，所以切分时笔记会全部留在左段，无法自动按画面时间拆到右段。静帧带精确时间，会按切点归到对应镜头。

## 标注镜头

选中 V1 镜头后，在右侧详情面板填写：

- 景别
- 机位
- 运镜
- 光线
- 声音
- 剪辑
- 摄法
- 台词
- 备注
- 镜头笔记

标签为多选。点击分类末尾的 `+` 可新增自定义标签；也可新建分类和首个标签。内置标签受保护，空分类才允许删除。

笔记支持自动保存，`Ctrl+S` 可立即提交当前笔记。术语库支持新增、编辑、删除、检索、插入笔记及 JSON 导入导出。

## 截图与画面标注

播放到目标画面后，点击“静帧截图”或按 `S`。截图会记录精确时间点，并作为镜头缩略图或主静帧候选。

右侧画面区支持三种标注：

- 框选：标出主体、构图区域或视觉重点。
- 箭头：指出活动方向、视线或剪辑关系。
- 文字：添加简短说明。

静帧在导出缺失时会按镜头中点自动生成，但建议在关键镜头手工截图，以便获得更准确的画面。

## 学习统计

点击顶栏图表按钮打开统计面板：

- 标签分布：查看各景别、机位和运镜的使用频率。
- 镜头节奏：按镜号查看全片镜头时长和平均值。
- 拉片进度：有标签、有笔记或有关键静帧的镜头占比。

统计数据直接来自当前项目 SQLite，修改标注后可刷新查看。

## 保存项目与恢复

保存项目会生成 `.lapian` 文件，内部包含清单、项目数据库快照和可选资源。它适合：

- 备份项目标注。
- 把项目转移到另一台电脑。
- 在不影响原项目的情况下创建副本。

项目包默认携带静帧、缓存、导出等资源，视频可按保存选项决定是否一并打包。导入时如果项目 ID 冲突，会自动生成新 ID。

软件会自动记录上次项目、播放位置、选中镜头、左右栏状态、音量、滚动位置和时间线密度。即使异常关闭，下次启动也会尝试恢复。

如果上次项目被移动或删除，软件会扫描其他数据目录，并让你选择要恢复的项目。迁移只复制数据，不删除原目录。

## 导出分镜本

点击“导出分镜本”：

1. 选择导出镜头范围。
2. 选择表头显示项。
3. 选择图片策略：缩略图、完整画面或两者兼有。
4. 选择是否并入标签与笔记。
5. 选择 PDF 或 Word。

PDF 适合阅读和打印；Word 适合继续编辑。固定八列为镜号、时长、缩略图、景别、摄法、画面内容、台词、备注。

## AI 助手与本地 MCP

AI 助手提供五类任务：

- 检查分镜连续性
- 整理镜头笔记
- 导出摘要建议
- 术语标注建议
- 分镜画面描述

可以复制所选任务的完整提示词，或只复制项目快照。提示词明确要求模型区分事实、推断和待确认内容。

打开本地 MCP 后，支持的 Agent 可以读取当前项目，并调用 11 个工具读取镜头、检查连续性、写入笔记或标签、启动/查询/取消/应用检测、读取缩略图等。写操作会弹出授权窗口，可选择只允许一次或记住该 Agent。

## 设置

设置页可调整：

- 代理档位。
- 本地 Qwen3-VL 或 OpenCV 识别引擎。
- 本地模型失败时是否保留 OpenCV 结果。
- 数据根目录、缓存目录、导出目录和静帧目录。
- 代理、抽帧、波形、缩略图、导出子目录和静帧子目录。
- 本地 MCP 开关。
- 删除用户内容前是否二次确认。
- 镜头切分与合并快捷键。

`DSH_DATA_ROOT` 环境变量存在时，它会覆盖数据根目录并锁定设置。该模式主要用于开发测试和隔离运行。

## 数据安全

- 删除镜头、静帧、标签或术语是永久删除，不进入回收站。
- 默认开启二次确认；关闭后删除会立即执行。
- 修改数据根目录前，先保存 `.lapian` 项目包。
- 卸载工具默认保留项目、设置、数据库和缓存。
- 不要在公开 Issue 中上传 API Key、个人视频路径、数据库或未脱敏截图。
- 本地 AI 推理不上传视频；启用远程 AI 或 MCP 时，请自行确认目标 Agent 和服务的隐私边界。

## 卸载

开始菜单或控制面板中的卸载项可卸载安装版。也可运行独立卸载工具：

1. 完整卸载：删除应用本体和内置 AI，可选择是否删除用户数据。
2. 保留数据：删除应用与缓存，保留项目、settings 和数据库。
3. 自定义：逐项选择目标。

卸载工具会拒绝驱动器根、Windows 和 Program Files 等危险位置。执行前请关闭正在运行的个人拉片工作台。

## 常见问题

### 画面黑屏

确认 `resources/mpv/libmpv-2.dll` 存在，更新显卡驱动，并尝试重启软件。安装版不应手动移动 `resources` 下的运行库。

### 本地模型显示环境未就绪

确认安装目录中 `resources/local-ai` 完整存在。缺少模型文件或 Python 文件时，切换到 OpenCV 备用引擎仍可完成基本拉片。

### 导入后转码较慢

4K、HEVC 或长视频需要更长时间。可改用 360p 代理档位；播放和检测期间软件会自动限制转码并发。

### 检测没有切出合理镜头

可降低最短镜头时长或调整灵敏度，也可直接使用 V1 边界 trim、`Ctrl+K` 切分或相邻镜头合并。

### 切分或合并按钮不可用

切分要求当前镜头未锁定，且播放头位于镜头内部；合并要求两个镜头时间上首尾相接、均未锁定，并已用 `Shift`、`Ctrl` 或 `Cmd` 完成双选。V1 轨道锁定时这些操作也会停用。

### 切分后笔记只留在左段

这是当前数据结构的已知边界：镜头笔记没有独立时间戳，无法判断应归左段还是右段，因此拆分时统一保留左段；静帧会按时间自动归属。

### 导出缺少缩略图

先对镜头截图，或在重新导出时让软件按镜头中点自动生成缩略图。

### 工程拷到其他电脑后打不开

确认目标电脑有相同版本的软件，并优先使用 `.lapian` 项目包导入。若项目包未包含媒体，需要在新电脑重新指定原视频。

## 二次开发快速入口

源码使用 Electron、Vue 3、TypeScript、SQLite、libmpv、FFmpeg、OpenCV 和本地 Qwen3-VL。Windows 开发机需要 Node.js 22.12 或更高版本、npm 10 或更高版本、Python 3.12，以及 Visual Studio 2022 Build Tools 的 C++ 桌面开发工作负载。

```powershell
git clone https://github.com/YGSWGJR/personal-film-lab.git
cd personal-film-lab
npm ci
npm run prepare:runtime
npm run prepare:python
npm run dev
```

如需完整本地 AI：

```powershell
$env:PFL_LOCAL_AI_ARCHIVE = 'D:\downloads\个人拉片工作台-0.2.0-local-ai.7z'
npm run prepare:local-ai
```

验证与构建：

```powershell
npm run typecheck
npm run smoke
npm run build             # 应用主体安装包
npm run package:local-ai  # 独立本地 AI 资源包
npm run build:full        # 同时生成两者
```
