## 评测口径

- 合成帧尺寸：320×180；帧序列长度 40～120。
- 采样参数：`intervalMs=200`，`sensitivity=0.62`，`minShotSeconds=0.5`，`filterTransitions=False`。
- 容差：检出帧与真值帧距离 ≤ 2 帧视为命中，按距离从小到大贪心一一配对。
- 标准指标定义：TP=命中的真值；FP=未匹配的检出；FN=未命中的真值。
- precision=TP/(TP+FP)，recall=TP/(TP+FN)，F1=2PR/(P+R)。
- 当分母为 0 时按 1.0 记（表示该用例没有需要检出的事件且没有误报）；P+R=0 时 F1 记 0。
- flash 类真值为异常闪帧位置；本次按要求关闭转场过滤，评测的是事件候选检出能力，不代表生产模式会将这些闪帧输出为切点。
- fade 类真值取渐变区间中点。
