- **瓶颈在 4K x265 软解**：所有编码器耗时收敛在 ~12s（约 5x 实时），编码器差异仅 ±2s，说明 60s 素材的解码开销（x265 10bit 4K 软解）主导了总时长。替换编码器对代理转码提速空间有限；进一步提速应聚焦解码侧（硬解、降采样前置）或批量场景（T1-E 硬解的价值主要在批量/连续任务）。
