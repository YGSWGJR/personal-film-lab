# v0.3.0 发布说明

- 分支：`main`；tag `v0.3.0`
- 日期：2026-11-07

## 本版亮点（相对 v0.2.0）

### 分镜墙画布（对标 SHOTLOOM「分镜PPT」分四期落地）
1. **分镜墙画布**：全部镜头以卡片铺在无限画布上；滚轮以光标为锚点缩放（10%–400%）、ALT/两指平移、空格/中键抓手、Ctrl+0 复位；卡片可自由拖拽摆放（世界坐标持久化，删镜头随 CASCADE 清理）；视口虚拟化支撑 350+ 镜头项目。
2. **连线系统**：卡片右侧端口拖到另一张卡建立叙事顺序；**实线=主线、Shift 拖=备选虚线**；**1.2 防误触**（拖动距离不足 1.2 卡宽不建立连线）；悬停连线中点 × 删除。
3. **分组**：Shift 多选 ≥2 张卡成组（自动断开跨组连线），组为独立板子，放映不跨组；一键解散。
4. **卡片重排**：拖动后同水平带卡片手机图标式自动让位，位移批量落库。

### 分镜PPT 放映 + 标注
5. **放映**：双击卡片进入全屏 Cover Flow——当前图居中、左右露出相邻卡边缘、横平竖直切换（无回弹）；单张模式；孤卡单张、组内放映不跨组（作用域规则与竞品一致）。
6. **跟随播放**：按每镜真实时长推进进度条并自动切下一张（模拟放映）。
7. **标注工具集**：画笔/涂抹/直线/箭头/矩形/圆/文字/马赛克/橡皮（快捷键 1~9）+ 选择（A）；5 色+自定义色；**选中对象可直接改色**（竞品未做对）；**马赛克强制置底**；标注随镜头持久化并**回显到分镜墙缩略图**。
8. **按连线顺序导出图片**：一键把镜头图按主线顺序（无入边起点 DFS）导出为编号图片文件。

### UI 全量修复（0.2.0 用户实测问题）
9. 标签识别结果弹窗/删除确认框不再被视频画面盖住（原生 HWND 降层）。
10. 矮窗口（720px）底部播放控制条不再被裁掉。
11. 1200px 最小宽顶栏不再溢出重叠（"切分已应用"提示条自适应截断）。
12. MCP 授权弹窗不再被业务弹窗压住；弹窗内按空格不再播放视频（快捷键全让位）；Esc 逐层关闭弹窗。
13. 清理死代码/死样式；术语编辑窗限高；缩放胶囊自适应。
