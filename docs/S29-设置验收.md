## 2. 分项验收

### 2.1 S1-A 数据迁移向导 ✅（提交 e7ff067）
- **验收标准**：列出可迁移项目并一键复制 DB+资源目录，迁移后项目列表完整。
- **实现**：`handleDataRootChange`（index.ts）改数据根 → `scanCandidateRoots` 扫旧数据根列出候选（项目名/镜头数/更新时间，过滤已存在）→ 挂起迁移待确认（`SETTINGS_MIGRATION_NOT_PENDING` 状态机）→ 确认后 `importProjectFrom` 事务复制 DB（projects/shots/stills/scenes/notes+标签去重）+ 资源目录 → 失败回滚删已建目录；取消/退出恢复旧目录。
- **联动**：App.vue toast「数据目录设置已保存到 …，正在检查旧项目是否可以迁移」。
- **实测**：当前数据根 `G:\拉片\项目数据目录`；迁移链路代码核对通过。

### 2.2 S1-B 保存回读验证 ✅（提交 8433ab7）
- **验收标准**：写盘重读比对一致才成功，不一致报 SETTINGS_VERIFY_FAILED，成功 toast 显示保存路径。
- **实现**：`set()` 写盘 → `beforeVerify` → `verifyStoredSettings`（重读 settings.json，10 个路径字段逐项比对 `SETTINGS_PATH_FIELDS`）→ 不一致抛 `SETTINGS_VERIFY_FAILED`（'设置写入后校验不一致，请重试'）；失败自动回滚重写旧设置；成功 toast「设置已保存到 {settingsPath}，新的缓存、导出和截图路径已生效」。
- **实测**：settings.json = `C:\Users\asus\AppData\Roaming\personal-film-lab\settings.json`，当前值 dataRoot/cacheDir/exportDir/stillDir 均指向 `G:\拉片\`。

### 2.3 S1-C 环境变量锁定说明 ✅（提交 2ab4bb6）
- **验收标准**：弹窗内展示 DSH_DATA_ROOT 解除指引与检测按钮。
- **实现**：SettingsModal 弹窗：展示当前 `DSH_DATA_ROOT` 值 + 四路解除指引（CMD `set DSH_DATA_ROOT=` / PowerShell `Remove-Item Env:DSH_DATA_ROOT` / Git Bash `unset DSH_DATA_ROOT` / 系统级环境变量删除步骤）+「检测是否仍被锁定」按钮（`checkEnvironment`，返回已解除/仍锁定两种结果）。
- **实测**：`environmentDataRoot()`（paths.ts）读取环境变量；设置写入受 `SETTINGS_ENV_LOCKED` 保护。

### 2.4 S1-D 设置界面全量 10 项路径可配置 ✅（提交 1733d40）
- **验收标准**：10 项保存位置均可改，子项继承缓存根，还原默认按钮，改数据根/缓存根触发迁移向导。
- **实现**：
  - `pathItems` 10 项：dataRoot（项目数据目录）/ cacheDir（缓存目录）/ exportDir（导出目录）/ stillDir（截图目录）/ proxyCacheDir / frameCacheDir / waveformCacheDir / thumbCacheDir / exportSubDir / stillSubDir，v-for 渲染均可改（可选目录留空即继承）。
  - 子项继承：paths.ts `resolveProxyCacheDir`=cacheDir/proxies、`resolveFrameCacheDir`=cacheDir/frames、`resolveThumbCacheDir`=frameCacheDir/thumbs、`resolveAudioWaveformCacheDir`=cacheDir/audio-waveforms、`resolveExportSubDir`=exportDir、`resolveStillSubDir`=stillDir（设置显式值时覆盖继承）。
  - 还原默认按钮：回填 `defaultSettings()`（userData/lapian 体系）。
  - 数据根/缓存根变更：`storageRootChanged` 提示 + 触发 `handleDataRootChange` 迁移。
- **实测**：settings-service `SETTINGS_PATH_FIELDS` 10 字段全量校验；SettingsModal submit 提交 4 根 + 6 子项；tsc 0 错误。

### 2.5 STILL-TIME 静帧截图时间记忆 ✅（提交 b9ddbe8）
- **验收标准**：库 time_ms = 文件名 = 导出标注 = 图片元数据 四者一致；导出 PDF 截图下方可见 HH:MM:SS.mmm。
- **实现**：
  - 库：`stills.time_ms = capturedTimeMs`（capture-service.ts:69/77）。
  - 文件名：`still-{String(capturedTimeMs).padStart(8,'0')}-{uuid8}.png`（毫秒精度）。
  - 图片元数据：`writePngTimeMetadata` 写 PNG tEXt 块（`Time`=formatTimeMs、`TimeMs`=精确毫秒）。
  - 导出标注：`renderStillTime` → `<div class="still-time">HH:MM:SS.mmm</div>`（formatTimeMs，shared/time.ts 小时累计不截断）；docx 导出同款段落。
- **实测**：四者一致链路代码核对通过；格式 `00:00:43.120` 样式。

### 2.6 W1-A/B 弹层联动降层 ✅（提交 0bd532c / 1e96f9b）
- **W1-A 验收**：检测/设置/导出/截图/术语/统计弹层打开时 player.setLayer(hidden)，关闭恢复。
  - `overlayOpen` 聚合六类弹层（detection/export/term/settings/stats/importWizard）；`watch(overlayOpen)` 打开 → `hidePlayerForOverlay` 记 `pendingPlayerLayer` → `applyPlayerLayer('hidden')`；关闭 → `restorePlayerLayer` 恢复 pending??normal。
  - IPC `PLAYER_SET_LAYER` → `player-service.setLayer` → `native-overlay.setZ(hidden)`（HWND 置底/隐藏）。
- **W1-B 验收**：弹层关闭时用户手动层级不被覆盖，保持 hidden 不变。
