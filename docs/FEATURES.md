# 个人拉片工作台已实现功能

适用版本：`0.3.1`  
更新日期：2026-11-05

本清单只列出当前源码中已经落地的能力。尚未实现或仅有界面占位的功能单独列在文末。

## 输入与项目

- 打开本地视频文件，支持 FFmpeg 可解码的常见封装与编码。
- 使用 `ffprobe` 读取时长、分辨率、帧率、容器、音视频编码、码率和文件大小。
- 原片可先播放，缩略图、代理和波形随后在后台生成。
- 代理转码支持 360p、540p、720p 三档，不放大源视频。
- 同一素材与档位使用哈希缓存，重复导入可直接复用。
- 转码队列支持运行数、等待数和进度显示。
- 播放或镜头识别期间自动降低转码并发，任务结束后恢复。
- 检测 GPU 与显存状态；NVIDIA 环境可使用 CUDA/NVENC 加速并回退到软件编码。
- 支持从其他数据目录扫描并导入 `.lapian` 项目。
- 数据根目录切换时可预览旧项目并选择迁移、跳过或取消。
- 支持示例工作区与最近项目切换。

## 播放与时间线

- 基于 libmpv 的原生视频渲染。
- 空格播放或暂停，左右方向键逐帧前后移动。
- `Shift+←/→` 对附近镜头边界或标记执行一帧微调。
- 上、下方向键在镜头边界、静帧和笔记标记之间跳转。
- `Enter` 跳到当前选中镜头起点。
- 支持精确 seek 和帧级检查。
- 四档播放速度：0.5x、1.0x、1.5x、2.0x。
- `[`、`]` 切换倍速，切镜头或新素材时回到 1.0x。
- 音量滑块、精确百分比输入、静音和持久化。
- `M` 静音，`Ctrl+↑/↓` 每次调整 1%，`Shift+Ctrl+↑/↓` 每次调整 10%。
- 原生视频层级支持正常、置底和隐藏。
- 打开设置、导出、检测等覆盖层时临时隐藏原生视频，关闭后恢复原层级。
- V2 缩略图参考轨、V1 镜头剪辑轨、A1 音频波形轨。
- 轨道高度支持 1、48、96、144、192、240 px。
- 横向密度支持 24、48、96、192、384、768 px/s。
- `+`、`-` 调整时间密度，`Ctrl+滚轮` 缩放，`Shift+滚轮` 平移。
- 时间线区域导航条可拖动到全片任意位置。
- V1 支持镜头选中、seek、左右边界 trim、显隐和锁定。
- V1 支持在播放头切分镜头，以及合并时间上无缝相邻的两个镜头。
- 切分、合并同时提供时间线工具栏、右键菜单和可配置快捷键三个入口。
- 合并采用“主选中镜头 + `Shift/Ctrl/Cmd` 点击相邻镜头”的最小双选方式，并在镜头列表与时间线上高亮伙伴镜头。
- 切分与合并走 SQLite 事务；切点按项目帧率对齐，失败不会留下半拆或半合记录。
- 拆分时语义字段和标签由两段继承；静帧按时间归到左段或右段；笔记因现有表结构没有时间字段而保留在左段。
- 合并保留时间较早的镜头记录，迁移并去重标签、笔记和静帧；可由设置中的删除二次确认控制确认弹窗。
- 锁定镜头禁止切分、合并和边界 trim；手动编辑的镜头标记为人工来源，重新检测时不会被自动结果覆盖。
- A1 支持音频包络、M/S 状态切换和波形缓存。
- 支持入点 `I`、出点 `O`，用于时间线选区和后续编辑操作。
- 支持手动在当前播放位置新增镜头。

## 镜头检测（S41 分阶段）

检测拆分为两个独立阶段，Qwen 不参与切点计算：

### 阶段一：镜头切分（boundary）

- TransNetV2（ONNX）+ OpenCV 混合边界检测；模型或 FFmpeg 缺失时自动回退 OpenCV。
- 切分完成后镜头与场景立即事务化写入数据库并自动应用，无需二次确认。
- 顶栏提示“切分已应用 · N 个镜头”，保留“开始标签识别”入口，可关闭。
- 已锁定或人工创建（origin='manual'）的镜头不会被覆盖；重叠候选跳过并如实显示数量。
- 缩略图按任务 ID 隔离生成，不再清空整个项目 thumbs 目录。
- 边界任务不依赖 Qwen 环境：OpenCV-only 用户可完整切分、手工标注、导出。
- 任务异步运行、可后台、可取消；检测帧按任务 ID 隔离，支持中文与 Unicode 路径。

### 阶段二：标签识别（labels，用户主动启动）

- 只分析当前数据库中的真实镜头，每个镜头取中点代表帧。
- Qwen3-VL 8B W4A8 输出景别、摄法、备注与六类标签，结果仅生成预览，不自动写库。
- 预览弹窗支持逐镜头选择、全选/清空；提供两种应用策略：
  - `覆盖全部选中镜头`：覆盖景别/摄法/备注并替换六类受管标签（自定义分类标签保留），需二次确认。
  - `保留我的标注，应用其余`：按 `manualFields` 字段级人工保护精确保留用户改过的字段。
- 字段级保护：人工编辑景别/摄法/台词/备注或打标签都会记录到镜头的 `manualFields`；split 继承、merge 取并集。
- 应用过程为单事务：单个镜头因切分/合并失效（LABEL_RESULT_STALE）或被锁定时仅跳过，不串写新镜头；数据库错误整体回滚。
- 关闭/取消预览不写库，不改变已落库切分与人工标注；台词、笔记、静帧、缩略图、起止时间和锁定状态永不被标签应用修改。

## 分镜墙画布与分镜PPT（0.3.0）

- 顶栏「分镜墙」打开全屏画布：镜头卡自由摆放、滚轮光标锚点缩放（10%~400%）、ALT/两指平移、空格/中键抓手、Ctrl+0 复位；视口虚拟化。
- 卡片布局按项目持久化（世界坐标）；删除镜头布局随 CASCADE 清理。
- 连线：卡片右侧端口拖到目标卡建立叙事顺序；实线=主线、Shift 拖=备选虚线；拖动不足 1.2 卡宽不建立（防误触）；悬停连线中点 × 删除。
- 分组：Shift 多选 ≥2 张卡成组，组间连线自动断开，组为独立板子；放映不跨组；支持解散。
- 分镜PPT 放映：双击卡片进入全屏 Cover Flow（当前图居中、左右露相邻、无回弹横移）；单张模式；孤卡单张。
- 标注工具集（快捷键 1~9 + A）：画笔/涂抹/直线/箭头/矩形/圆/文字/马赛克/橡皮；选中可改色；马赛克置底；标注随镜头持久化并回显到墙卡缩略图。
- 跟随播放：按每镜时长推进进度条并自动切下一张（模拟放映）。
- 按连线顺序一键导出镜头图片到 exports/wall/。

## 镜头标注

- 六类内置标签：景别、机位、运镜、光线、声音、剪辑。
- 每个分类支持多选标签。
- 支持新增自定义标签。
- 支持新增自定义分类。
- 支持删除空分类和自定义标签。
- 内置标签带保护，项目包保存时可幂等映射，不产生重复约束或悬空引用。
- 镜头字段包含镜号、起止时间、时长、景别、摄法、台词、备注和来源。
- 支持镜头笔记自动保存。
- 支持术语库的新增、编辑、删除、检索、插入笔记和 JSON 导入导出。
- 支持以右键菜单或 `Delete` 删除镜头，并默认二次确认。

## 静帧与画面标注

- 在播放头位置截取当前静帧。
- 支持按指定毫秒时间点精确抽帧。
- 静帧保存截图时间和来源角色。
- 镜头缺少缩略图时可自动在镜头中点生成。
- 支持框选、箭头和文字三种画面标注。
- 标注数据随静帧保存，可在详情面板重新查看。
- 支持删除静帧，并默认二次确认。

## 项目与数据

- 使用 better-sqlite3 保存项目、场景、镜头、静帧、标签、笔记和术语。
- SQLite 启用 WAL、外键和事务写入。
- 启动时按 `PRAGMA user_version` 自动执行数据库迁移。
- `.lapian` 项目包包含清单和 SQLite 快照，可按选项携带静帧、缓存、导出和视频。
- 导入项目时自动重映射冲突 ID，必要时为项目名添加导入标记。
- 自动保存当前项目、播放位置、选中镜头、侧栏折叠、音量、滚动位置和时间线设置。
- 异常退出后可从 `session.json` 恢复工作现场。
- 上次项目缺失时扫描其他数据根并引导恢复。
- 删除用户内容前默认弹出确认，文件永久删除且不进入系统回收站。

## 导出

- 导出 PDF 分镜本。
- 导出可编辑 Word 分镜本。
- 支持选择导出镜头范围。
- 支持自定义表头。
- 支持缩略图、完整画面或两者兼有的图片策略。
- 固定八列为镜号、时长、缩略图、景别、摄法、画面内容、台词、备注。
- 支持将标签与镜头笔记并入导出字段。
- 缺少缩略图时按镜头中点自动生成。
- PDF 使用 A4 竖版、封面和重复表头。
- Word 显式使用 Microsoft YaHei，保持表格可编辑。
- 导出进度实时显示。

## 学习统计

- 标签分布横向柱状图，覆盖全部景别、机位和运镜标签。
- 镜头时长节奏折线图，显示每个镜头的时长和平均值。
- 拉片进度环形图，按有标签、有笔记或有关键静帧统计完成度。

- 统计面板支持刷新和错误重试。

## AI 助手与 MCP

- AI 助手提供五类任务：分镜连续性、镜头笔记整理、导出摘要、术语建议、画面描述。
- 可复制所选任务的完整提示词和项目快照。
- 可只复制结构化项目数据，不附带任务。
- 本地 MCP 使用 `127.0.0.1`、随机端口和临时 Bearer Token。
- MCP 写操作请求桌面端用户授权，可记住可信 Agent。
- MCP 共暴露 11 个工具：
  - `list_shots`
  - `get_shot_detail`
  - `check_continuity`
  - `write_shot_note`
  - `get_project_summary`
  - `run_shot_detection`
  - `get_detection_job`
  - `cancel_detection`
  - `apply_detection`
  - `write_shot_tags`
  - `get_shot_thumbnail`

## 设置与运行环境

- 可配置数据根目录、缓存目录、导出目录、静帧目录。
- 可单独配置代理、抽帧、波形、缩略图、导出子目录和静帧子目录。
- 可配置切分与合并快捷键，默认分别为 `Ctrl/Cmd+K` 与 `Ctrl/Cmd+Shift+G`。
- 保存设置后回读验证，不一致时回滚并报告错误。
- `DSH_DATA_ROOT` 环境变量可锁定数据根，用于隔离测试或便携部署。
- `G:\拉片\软件数据` 可用时优先使用；不可用时回退到系统 userData。
- 支持内置 Python/OpenCV 运行时，不要求用户预装 Python。
- 支持内置 Python 3.13、PyTorch CUDA、Transformers、Accelerate、BitsAndBytes、ComfyUI 和 Qwen3-VL。
- 支持代码签名之外的本地 NSIS 安装、快捷方式和卸载注册表。
- 独立卸载工具支持完整删除、保留数据和自定义模式。
- 卸载工具执行前扫描应用、设置、数据、环境变量、注册表和进程。
- 卸载工具拒绝驱动器根、Windows、Program Files 等危险目标。
