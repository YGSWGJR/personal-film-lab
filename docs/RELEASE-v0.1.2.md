# 个人拉片工作台 v0.1.2

发布日期：2026-10-25

这是 `v0.1.1` 之后的补丁更新，安装包已按 S32 重新打包，包含最新的 userData 重定向及卸载器适配。

## 本版更新

- 将 Electron `userData` 定向到 `G:\拉片\软件数据`，避免敏感状态写入系统盘。
- 自定义目录不可用时自动回退到默认 userData，并记录警告。
- 更新卸载器，使其识别新的用户数据目录。
- 支持卸载器备份目录覆盖。
- 包含 `v0.1.1` 中的设置迁移、10 项路径配置、静帧时间、弹层层级保护、镜头/静帧删除及检测修复。

## 系统要求

- Windows 10/11 x64

## 安装

下载并运行 `personal-film-lab-setup-0.1.2.exe`。免安装用户可下载 `win-unpacked` 压缩包。

源码可通过 GitHub 自动生成的源码包或本次附带的源码 ZIP 下载。
