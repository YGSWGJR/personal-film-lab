# S26 拉片软件功能优化与问题修复策划案

> 编号：S26 ｜ 批次：P2-6 数据卫生 ｜ 依据：产品方案 V2（docs/产品方案V2.pdf）+ 修复批次实测结果
> 状态：验收文档（S26~S29 四份之一）｜ 日期：2026-10-25

## 1. 产品定位与目标

**个人拉片工作台**：面向个人学习电影语言与影像分析的桌面工具。链路：导入影片 → 智能/手动切分镜头 → 标注镜头语言 → 静帧截图 → 一键导出标准分镜本（PDF / Word）。

- 定位变化：不做教学分发，只做个人拉片工作台；核心交付物为「标准分镜本」；教师端/学生端/商业化全部移除。
- 桌面框架：Electron；播放内核：libmpv（帧级控制）；视频处理：FFmpeg；色彩检测：OpenCV；本地存储：SQLite。

## 2. 六大功能模块（产品方案 V2）

| 模块 | 能力 | 实现状态 |
|---|---|---|
| 1 导入 | 本地多格式拖拽导入（MP4/MKV/MOV…）、FFmpeg 转码代理流畅播放 | ✅ T1 批次优化（见 §3） |
| 2 镜头分析 | 色彩检测自动切分（饱和度/对比度/色调）、手动打点、边界微调、场景分组、灵敏度可调 | ✅ D1 批次优化（见 §4） |
| 3 静帧截图 | 任意帧一键截取（快捷键 S）、框选/箭头/文字标注、截图库关联镜头 | ✅ STILL-TIME 时间记忆（见 §5） |
| 4 标注与笔记 | 预置标签（景别/机位/运动/光线/声音/剪辑）、自定义标签+术语库、镜头笔记 | ✅ |
| 5 分镜本导出 | 标准分镜表、导出 PDF 与 Word、导出前预览勾选镜头范围 | ✅ |
| 6 学习统计 | 标签分布、镜头时长节奏分析、个人进度复盘 | ✅ 统计面板 |

## 3. 转码与播放优化批次（T1）

| 任务 | 目标 | 实测结论 |
|---|---|---|
| T1-A 编码器矩阵自动探测 | 自动选最优硬件编码器 | ✅ ffmpeg -encoders 白名单解析 + 厂商匹配（NVIDIA/Intel/AMD），进程级缓存 |
| T1-B 分辨率降档 | 低配机流畅播放 | ✅ auto 档 srcHeight/2 夹取 [240,540]（4K→540p），三档 preset/cq/maxrate |
| T1-C 音频直拷 | 不重编码音轨 | ✅ 白名单 {aac,mp3,ac3,eac3,opus,flac} 直拷，GOP=fps×2 |
| T1-D 代理队列+缓存 | 重复导入秒开 | ✅ sha256 缓存（实测二次导入秒开），hash 去重防重复转码 |
| T1-E 抽帧硬解 | 抽帧/截图加速 | ✅ cuda→d3d11va→none，失败自动回退软解 |
| T1-F 联合基准+自动选优 | 量化性能 | ✅ 5 编码器×3 分辨率矩阵，选优 h264_nvenc@540p（见 S28） |
