## 2. 分项验收

### 2.1 D1-C 闪白去伪修复 ✅
- **缺陷**：原 `confirm_cut` 用 index-1/index+1 跳过当前帧参与确认，单帧闪白被误滤。
- **修复**：当前帧参与确认逻辑，消除单帧闪白误滤。
- **验证**：单测 `python -m unittest test_detection_algorithms -v`（tests/unit/detect 下）从 3 过 2 修复为 **4/4 全过**。

### 2.2 D1-E 抽帧清理与镜头微缩图 ✅
- `finally` 三出口清理检测抽帧临时目录（正常/失败/异常均清理，无残留）。
- 每镜头生成 160px 微缩图；`Shot`/`ShotPreview` 补 `thumbnail` 字段，列表/导出使用。
- 验证：代码核对 + smoke 断言覆盖。

### 2.3 D1-回归：5 类素材检测精度基线 ✅
- **评测口径**：合成帧 320×180、帧长 40~120；`intervalMs=200`、`sensitivity=0.62`、`minShotSeconds=0.5`、`filterTransitions=False`；检出与真值 ≤2 帧贪心配对。
- **总体指标**：**Precision=0.737 / Recall=0.737 / F1=0.737**（16 合成用例：hardcut/fade/flash/pan/occlusion 五类）。
- **短板（如实记录）**：fade 检出偏早多报（真值取渐变中点）；flash-4 四闪全漏（关闭转场过滤下的候选能力评测，不代表生产模式输出为切点）。
- **可复现**：`python -m unittest tests.regression.detect.eval_detect -v`；重跑结果与提交版报告 MD5 一致。

### 2.4 P1-B 检测前校验 ✅（提交 692a830）
- `getDetectProject`：PROJECT_NOT_FOUND → 「找不到该项目：可能已删除，或数据目录已变更。请通过启动导入向导恢复项目，或重新导入素材」。
- `resolveDetectSource`：DETECT_SOURCE_MISSING 区分两案——无视频路径 / 文件被移动删除，均给重新导入指引并附原路径。

### 2.5 P1-E 检测环境自检 ✅（提交 ad0f61a）

## 4. 结论与遗留

- 检测链路验收**通过**：闪白缺陷修复、抽帧清理、精度基线、前置校验、环境自检五项全部满足验收标准。
- 遗留（未立项）：① fade 检出偏早多报优化；② flash 类全漏场景（异常闪帧检出）是否作为事件检出能力增强；③ h264_amf 剔除（与检测无关，归 T1 转码联动）。
- 复现方式：单测与回归评测命令见 §2.1 / §2.3，均为可复现确定性输出。
