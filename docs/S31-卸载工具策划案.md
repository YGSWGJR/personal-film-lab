# S31 卸载工具策划案

> 编号：S31 ｜ 状态：策划案（待评审）｜ 日期：2026-10-25
> 目标：为「个人拉片工作台」提供干净、可选的完整卸载能力，支持软件流通场景下的卸载交付。

## 1. 背景与目标

安装包（Setup 0.1.0.exe，electron-builder NSIS）已具备基础卸载项，但**只删除应用本体文件与注册表项**。软件运行后会在多处产生用户数据、缓存与残留（实测见 §2），基础卸载后这些内容全部留在磁盘，导致：
- 卸载不彻底：Roaming 残留 settings.json / session 垃圾 / Electron 缓存，重装后旧配置与旧会话复活；
- 数据泄漏：`G:\拉片\` 下的项目数据、截图、导出仍占磁盘并含用户创作内容；
- 环境变量残留：`DSH_DATA_ROOT`（S1-C 锁定机制）卸载后不清理，重装会被「环境锁定」弹窗拦截；
- 流通不便：作为交付给其他用户的软件，卸载工具必须干净、安全、可解释。

**目标**：提供「卸载向导」，一次完成——应用文件、用户设置、缓存、项目数据、环境变量、注册表六类清理，且默认保护数据、允许保留数据重装。

## 2. 现状与缺口（实测 2026-10-25）

| 项 | 实测位置 | 现状处理 |
|---|---|---|
| 应用本体 | `D:\工作软件\拉片\personal-film-lab\`（自定义安装，含 resources\python 内嵌运行时） | ✅ NSIS 卸载删除 |
| 卸载注册表项 | HKCU `...\Uninstall\个人拉片工作台 0.1.0` | ✅ NSIS 自清 |
| 用户设置 | `C:\Users\asus\AppData\Roaming\personal-film-lab\settings.json`（10 项路径字段，S1-D） | ❌ 残留 |
| 会话/缓存垃圾 | 同 Roaming 下：`lapian\`、`session (2)~(46).json`（实测 46 个）、`*.tmp`（实测约 50 个）、`Cache/GPUCache/ShaderCache/Local Storage/Network/DIPS…`（Chromium 全类） | ❌ 残留 |
| 项目数据 | `G:\拉片\项目数据目录\`（lapian.db + projects 资源） | ❌ 残留 |
| 缓存数据 | `G:\拉片\缓存目录\`（proxies 代理、frames 抽帧、waveform、thumbs、preferred-encoder.json） | ❌ 残留 |
| 导出/截图 | `G:\拉片\导出目录\`、`G:\拉片\截图目录\` | ❌ 残留 |
| 环境变量 | `DSH_DATA_ROOT`（S1-C 锁定来源） | ❌ 残留 |
| 快捷方式 | 开始菜单/桌面（安装时 NSIS 创建） | ✅ 随卸载删 |

**结论**：基础卸载只完成 2/8 类，缺 6 类清理能力 → 需独立「卸载工具」补齐。

## 3. 卸载范围清单（六类）

| 类别 | 目标 | 判定方式 |
|---|---|---|
| A 应用本体 | 安装目录整树（含 resources\python、ffmpeg） | 注册表 InstallLocation / 安装器同级 exe 目录 |
| B 用户设置 | Roaming\personal-film-lab 全目录（settings.json + session + 缓存垃圾） | 已知固定路径 |
| C 数据根 | `G:\拉片\` 四目录（项目数据/缓存/导出/截图） | **解析 settings.json 10 路径字段**（不写死，尊重 S1-D 用户自定义） |
| D 环境变量 | 用户级 `DSH_DATA_ROOT` | 注册表 Env / [Environment]::GetEnvironmentVariable |
| E 注册表 | HKCU Uninstall 键 + 安装器自身 | NSIS + 显式清理 |
| F 运行进程 | electron 主进程/子进程 | 任务快照按可执行名匹配，先关后删 |

## 4. 卸载工具方案

### 4.1 形态
- **独立卸载器**（NSIS 段扩展 + 前置扫描器），随安装包分发；卸载入口：开始菜单「卸载个人拉片工作台」+ 控制面板卸载项 + 安装目录 Uninstall exe。
- 扫描器：内嵌 Node 单文件（复用仓库 settings-service 的 10 路径解析逻辑），读取 settings.json → 输出六类清单 JSON → 卸载界面展示。

### 4.2 三种卸载模式（用户选择）
| 模式 | 清理范围 | 适用 |
|---|---|---|
| **完整卸载** | A+B+C+D+E+F 全清 | 确定不再使用、彻底释放磁盘 |
| **保留数据卸载**（默认推荐） | A+B 缓存类 + D+E+F；**保留 C 数据根** | 想卸载软件但留项目数据，重装可恢复 |
| **自定义勾选** | 六类逐项勾选（默认全勾，数据类默认保留） | 精细化控制 |

### 4.3 保护与安全
- **路径安全守卫**：所有删除目标必须通过白名单校验（安装目录、已知 Roaming 路径、settings.json 解析出的路径）；解析失败（settings.json 损坏/被改）时**拒绝删除 C 类**并提示，防误删系统/用户文件。
- **二次确认**：展示清单摘要（各类文件数+体积）后确认；模式切换需再次确认。
- **备份选项**：完整卸载前可勾选「备份 settings.json + lapian.db 到卸载器同级 `卸载备份-{日期}\`」，zip 打包（复用仓库 zip 逻辑），重装时可用。
- **进程守护**：先杀 electron 进程（按 exe 名+路径双匹配），杀失败则提示关闭软件后重试，不强制删占用文件。
- **失败日志**：每类删除结果写入 `卸载日志.txt`（成功/跳过/失败+原因），失败不阻断后续类。

### 4.4 执行顺序
杀进程 → 删 B（Roaming）→ 删 D（环境变量）→ 按模式删 C（数据根）→ 删 A（应用本体）→ 删 E（注册表卸载项）→ 清理快捷方式 → 完成页（展示日志路径与释放空间）。

## 5. 交互流程（向导 4 步）

```
第 1 步 检测  扫描六类清单，显示：安装位置 / 数据体积 / 残留项数
第 2 步 选模式 完整卸载 ｜ 保留数据卸载（推荐）｜ 自定义勾选
第 3 步 确认  清单摘要 + 备份选项 + 二次确认（红字警示不可逆）
第 4 步 执行  进度条逐类执行 → 完成页（释放空间统计 + 日志路径）
```

## 6. 验收标准

| # | 验收项 | 通过条件 |
|---|---|---|
| 1 | 应用本体 | 安装目录整树删除 |
| 2 | Roaming | `...\Roaming\personal-film-lab` 整目录删除（保留数据模式仅删缓存类垃圾，留 settings.json 备份外） |
| 3 | 数据根 | 完整模式：`G:\拉片\` 四目录删除；保留模式：原样保留；自定义：按勾选 |
| 4 | 环境变量 | `DSH_DATA_ROOT` 用户级删除（GetEnvironmentVariable 返回空） |
| 5 | 注册表 | HKCU Uninstall 卸载项消失 |
| 6 | 进程 | 卸载期间无 electron 进程存活 |
| 7 | 重装验证 | 重装后：无「环境锁定」弹窗、无旧 session/缓存复活、可正常建库 |
| 8 | 安全 | settings.json 被篡改时拒绝删数据根；无任何路径逃逸 |
| 9 | 日志 | 卸载日志.txt 完整可读 |

## 7. 范围与版本

- **V1（本次）**：独立卸载器 + 三模式 + 安全守卫 + 日志；随 Setup 打包（安装包体积 +~1MB）。
- **V2（可选）**：卸载前数据导出向导（分镜本/项目 zip 打包）、多用户/多数据根扫描、命令行静默卸载（`/S --keep-data`）。
- 不在本次范围：卸载后清理其他软件共享的 ffmpeg；系统级（HKLM）安装支持（当前为 per-user 安装）。

## 8. 待确认项

1. 数据保留策略默认值：**保留数据卸载为默认**是否可接受（相比常见"卸载即全删"更保守，避免用户误删项目数据）。
2. 备份功能是否进 V1（建议进：成本低、安全兜底）。
3. 卸载工具是否单独做成小工具（不依赖安装器），便于先本地验证再并入打包。
