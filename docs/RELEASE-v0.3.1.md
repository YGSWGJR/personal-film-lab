# v0.3.1 发布说明

- 分支：`main`；tag `v0.3.1`
- 日期：2026-11-07
- 定位：**完善与修复版**（无新大功能）——数据一致性 + 分镜墙交互补齐 + 独立分镜本地基 + 投影预览

## 本版更新（相对 v0.3.0）

### 数据一致性（三处同步）
1. **截静帧 → 镜头缩略图即时同步**：镜头列表、分镜墙卡、分镜PPT 放映大图三处共用同一响应式缩略图；新静帧自动成为该镜头封面并持久化（新增 `shot:setThumbnail`）。
2. **切分/合并同步**：分镜墙卡片随镜头数据自动增删（切分新增卡、合并收卡、连线随 CASCADE 保留/清理）。
3. **序号顺延验证**：切分后右段序号 = 左段+1、后续镜头依次 +1；合并后无空洞（新增 smoke 断言）。
4. 标签识别天然作用于切分/合并后的全部镜头（既有 stale 跳过保护）。

### 分镜墙交互补齐
5. **多选**：`Ctrl/Cmd+点击` 切换选中、`Shift+点击` 追加；多选整体拖动（相对位移批量落库）。
6. **允许重叠**：取消拖动自动让位；卡片可自由叠放（后放的在上层，选中提升）。
7. **右键菜单**（卡片/空白两套）：断开此卡所有连线、设为主线起点、成组、解散所在组、删除节点（镜头引用节点仅从墙移除，镜头数据不动）、整理节点、全选、缩放到全部内容。
8. **整理节点**：连线链（主线优先）成行排布、未连线镜头按镜号网格排到下方独立区；`Ctrl+Z` 单层撤销。
9. HUD 新增「整理」按钮；删除节点不再连带改镜头数据。

### 独立分镜本（分镜功能独立呈现·地基）
10. **无拉片素材也能创作**：无项目/空项目时点击「分镜墙」直接进入独立分镜本创作模式（自动新建）。
11. **节点创作**：右键空白 → 添加节点·导入照片（系统文件选择器，图片复制进数据根 `projects/boards/` 并走安全协议访问）/ 黑底+文本 / 白底+文本（双击文本节点改标题，缩略图即时渲染）。
12. **节点编辑卡**：右键节点 → 编辑名称/持续时间/笔记。
13. 节点删除为真删（区别于镜头引用节点的"仅从墙移除"）。

### 投影预览（分镜本 → 拉片形态的第一步）
14. **并行多宫格**：放映时同一深度层的并行节点以宫格呈现，点击宫格切换主图。
15. **多轨条**：放映底部每条连线链渲染一条轨道，块宽 ∝ 持续时间，当前节点高亮——"轨道数随并行链无限增加"。
16. 持续时间驱动跟随播放推进。
